# Atlas source register

This describes the visitor-facing workflow in the current code. `/sources` is the live operational register; [data-sources.md](data-sources.md) documents search limits and privacy.

## Search providers

| Source | Product role | Scope and limitation |
| --- | --- | --- |
| Bluesky AppView | Public social discussion | Public search, last seven days, up to 25 indexed posts per phrase. English baseline adds `lang:en`; the selected lens uses its query phrase. Language is not author geolocation; excerpts are transient. |
| Lemmy instances | Public federated forum posts | Public API query to `lemmy.world`, `discuss.tchncs.de`, `feddit.org`, `jlai.lu`, `sopuli.xyz`, and `sh.itjust.works`; up to 20 recent matching posts per instance in seven days. Each post's language ID is resolved against that same instance's live `/api/v3/site` `all_languages` catalog; if that request fails or the ID is absent, the post remains visible with an unresolved label. It cannot match a provider language code; conservative script-only fallback can still include Korean, Japanese, or Hindi, while other unknown-language records are excluded from named-language summaries. Only the Germany- and France-focused community lenses use Lemmy's `local` listing (communities hosted on those servers); other country lenses use `all` (federated search) because no country-specific Lemmy server is configured. A server's country, language, and locally hosted communities do not verify poster residence or nationality. Finnish/English and Canadian English/French servers are general community views, not representative resident samples. Federation may duplicate posts; no blanket reuse license is implied. Instance terms and privacy links are listed on `/sources`. |
| Mastodon instances | Public hashtag conversation | Public hashtag timeline; posts older than 30 days are filtered, with up to 20 API items per tag and up to three bounded topic tags per selected instance. Tags are separate query/status/provenance views; untagged posts and posts without those tags are missed, and broad terms can add noise. For lenses configured as community-focused, Atlas sends Mastodon's documented `local=true` filter so the server returns only statuses hosted locally; this is a server-local sample, not a verified national or resident sample. Other selected instances use the default hashtag timeline and may include federated posts. Korean-, Japanese-, German-, French-, Brazilian Portuguese-, and Spanish-language/community-focused servers are configured for those lenses, but server availability does not guarantee fresh market-topic posts; recent Korean market-tag probes were stale under the 30-day cutoff, and there is no reviewed local-focused instance configured for India. Accounts self-marked automated by the instance remain citable but their text is excluded from AI summaries. Atlas does not use full-text status search because Mastodon's official docs say it depends on server search configuration and authenticated requests. Instances can restrict public access. |
| Stack Exchange API | Licensed expert Q&A | Economics, Quantitative Finance, and Personal Finance & Money; Japanese, Portuguese, or Spanish Stack Overflow titles for the corresponding language lens where configured. Title-only matches, individually CC BY-SA items with author/license attribution; 30-day visitor search. One platform operator, not general opinion. |
| The Conversation Atom feeds | Expert analysis context | Six first-party English editions; up to five exact headline matches per edition in 30 days, with author/date/link and item-level Creative Commons attribution/no-derivatives notice. Titles only are returned; one publisher's editions are not independent operators or audience/geographic samples and are excluded from AI discussion synthesis. |
| Crossref | Global scholarly research context | Free public API, no key or signup; one small title search, up to 12 DOI-linked records published in the last five years. Bibliographic metadata only, no abstract/body; not a community or country sample and not a measure of study quality. |
| OpenAlex | Global scholarly research context | Keyless casual-use API, no account or payment method; up to 25 provider hits are checked locally and at most 12 five-year title matches are returned. Only ID, DOI, title, date, type, and open-access flag are requested; no abstracts/authors. Metadata is CC0. Keyless quotas are shared/provider-controlled and Atlas cannot guarantee availability; this evidence is not discussion, country opinion, or a study-quality rating. |
| arXiv | Open preprint metadata | Public keyless Atom API; at most 12 five-year title matches, retaining title/ID/date/category and discarding abstracts/authors. Metadata is CC0; underlying papers have item-specific rights. Preprints may not be peer reviewed and do not represent discussion or country views. Identical queries are cached in volatile server memory for 24 hours and upstream requests are spaced at least three seconds apart per instance. Required arXiv acknowledgment appears in the source register. |
| Manifold Markets | Crowd-forecast context | Read-only, no-key public API; up to 20 open binary market matches sorted by recent volume. Atlas keeps only active MANA play-money markets with positive recent volume and liquidity, and displays their probability and MANA measures below the summaries. This is one self-selected forecasting platform, not real-money price discovery, a representative survey, a verified probability, or a country view. It is excluded from AI summaries. Its documented API permits non-commercial/personal projects; a commercial Atlas would need a separate written agreement. |
| World Bank · World Development Indicators | Official statistical context | Keyless public API, queried only for explicit inflation/CPI, GDP-growth, and unemployment searches. Retrieves at most three latest annual values for the U.S., selected country, and World aggregate. Each row shows year, unit, direct series link, and CC BY 4.0 attribution. Macro data is not discussion, a real-time price, or a population opinion; latest years may differ or lag. Kept out of AI summaries. Broad World Bank metadata keyword search was screened out as too noisy. |
| EIA · U.S. energy benchmarks | Official market-data context; optional/unconfigured until key is provided | Free EIA API, but operator registration and acceptance of EIA API terms are required. When privately configured, searches only explicit crude oil/WTI/Brent, natural gas/Henry Hub, or broad energy-price concepts and returns up to five daily observations per mapped U.S. benchmark. Source results show date, units, series, attribution, and original EIA chart. Missing series or a latest observation older than 14 days is marked partial. U.S.-based reference prices are not the selected country’s local price, a complete global market quote, or public discussion; excluded from AI summaries. Key is server-only. |
| SEC EDGAR | Official issuer filing context | Free, public, no-key filing metadata for an exact ticker/company-name match; requires an operator-configured User-Agent with a contact email and server-side request. Up to 10 recent 10-K, 10-Q, 8-K, 20-F, 40-F, or 6-K document links within three years; Atlas retrieves index metadata only, not filing bodies. Covers SEC registrants, including some foreign issuers, not all companies or markets. Primary-source context only; never counted as community evidence or sent to the AI summary. A no-match means only that the exact query did not match the SEC issuer index. |
| Reddit | Excluded | Reddit's current developer guidance says research use must go through its separate Reddit for Researchers program; ordinary Data API access is not an authorized research route. No API requests or page scraping are made. Reconsider only if Atlas qualifies for and receives compatible research-program authorization. |
| Global Voices editions | International reporting context | Non-U.S. lens only: twelve language editions, headline metadata only, 30-day window and capped results. One publisher's editions are not independent forums or country samples. |

The form compares a baseline query with one selected country/language lens from eight options: U.S./English, South Korea/Korean, Japan/Japanese, Germany/German, France/French, Brazil/Portuguese, India/Hindi, and Spain/Spanish. Baseline language handling varies by provider; it is not a verified U.S. sample. These are query and community lenses, not verified contributor geographies. The product presents the baseline and selected-language summaries separately and lists sources beneath; it does not combine the international sample into one national-opinion estimate.

Hacker News is retired from visitor search while content display/reuse authorization remains unresolved. Its public search endpoint is technically reachable, but public API access and the API repository's MIT license (for implementation/documentation) do not grant a blanket license to redistribute user comment text. Y Combinator's [current terms of use](https://www.ycombinator.com/legal) restrict copying, distribution, and automated extraction from its site absent express authorization. No compatible content license or explicit authorization has been obtained; do not query, display, or summarize comments until the operator resolves this permission question. Stack Exchange title-only Q&A is included as a separate evidence class. Wikimedia talk pages and scheduled feeds shown in operational health are not automatically included in this search. Metaculus was screened but not added: its current API requires authenticated requests, whereas this product is limited to no-login public sources; no account token or access request was created. See the [official Hacker News API documentation](https://github.com/HackerNews/API) and [Y Combinator terms](https://www.ycombinator.com/legal).

India-specific Discourse forums TradingQ&A and ValuePickr were screened as potentially useful investing communities. Both operators' published `robots.txt` files disallow `/search`, so Atlas does not call their search routes. ValuePickr's terms additionally license user contributions under CC BY-NC-SA 3.0, which imposes attribution, non-commercial, and share-alike requirements on reuse. Reconsider only if an operator provides an allowed search route or written permission compatible with Atlas. A public JSON endpoint is not permission to ignore crawler directives or content licenses.

Fedora Discussion's public Discourse search endpoint was screened on 2026-10-11 after confirming its [terms](https://discussion.fedoraproject.org/tos) default user contributions to CC BY-SA 4.0. The endpoint returned 50 broad matches for `GPU` (many support topics), none for `semiconductor demand`, and one unrelated mouse-use topic for `oil prices`; subsequent bounded checks received HTTP 429. This small operational probe does not establish long-run availability or general irrelevance, but it is not adequate evidence to add the source as a market-community view. It remains in scheduled title-metadata ingestion only; do not promote it to visitor search without a relevant-query benchmark and stable, permitted access.

Misskey.io was screened but not added. Its API documentation lists `POST /api/notes/search` as not requiring a credential, but its operator's terms say data collection beyond personal use is prohibited and require advance contact for annual collection of 500 or more records. A public endpoint is not blanket permission; Atlas cannot enforce that annual aggregate limit across serverless instances and visitors, so it remains off unless the operator clarifies/authorizes the intended use. See [Misskey.io API docs](https://api-doc.misskey.io/api-7254035) and [MisskeyHQ terms](https://support.misskey.io/ja/articles/14193143-%E5%88%A9%E7%94%A8%E8%A6%8F%E7%B4%84).

AI translation and summaries are attempted automatically when a visitor submits a search; the privacy notice describes that the topic and up to 16 short excerpts may be sent to Groq. Before AI submission, discussion snippets must pass a conservative market/economic vocabulary screen in the eight configured languages; this is not semantic relevance validation and may omit relevant posts or admit false positives. The screen runs before source balancing and the eight-excerpt cap; the UI reports how many unique candidate excerpts it rejected. For a named-language overview, understood matching provider labels are eligible and explicit mismatches are excluded. Missing labels or unresolved Lemmy IDs may use conservative script detection for Korean, Japanese, or Hindi only; other unknown-language records remain visible but are not summarized. Lemmy language IDs are mapped using each post's own instance catalog; unknown IDs remain unresolved rather than guessed. The browser and server both enforce this filter. Each summary claim must be one sentence and have exact source IDs; comparison claims must cite both sides. Citation-ID validation does not prove that the cited text entails the claim. Embedded links, email addresses, and @handles are removed from excerpts; citation URLs and attribution fields are not sent. There is no per-search AI opt-in. Server configuration (`GROQ_FREE_TIER_ENABLED=true` and a private key) is required. Production AI requests use shared Supabase limits of 6/minute and 60/day per client, plus 10/minute and 400/day globally; client identifiers are HMACed, not stored as raw IPs. If the shared limiter is unavailable, production fails closed. The code does not verify an account's Groq billing status; operators must independently confirm free-tier eligibility and must not enable paid billing for Atlas. Groq's free availability and rate limits are not guaranteed by Atlas. Groq's [data handling](https://console.groq.com/docs/your-data), [free-plan rate limits](https://console.groq.com/docs/rate-limits), and [billing FAQ](https://console.groq.com/docs/billing-faqs) apply; see Atlas's [privacy notice](https://signal-scout-xi-ruby.vercel.app/privacy).

No separate public machine-translation endpoint is used. Groq can prepare a local-language phrase when enabled; if it is unavailable, Atlas searches the original phrase, labels the fallback, and lets the researcher enter a local phrase. A translation service is not added merely because its endpoint is reachable: a replacement must have a verified no-cost allowance, acceptable terms/privacy, useful quality for short market queries, and a stable deployment the operator can rely on. LibreTranslate is open-source software, but a self-hosted instance needs separately provisioned compute; no specific anonymous public deployment passed that operational and terms review. This means localized discovery can be sparse when Groq is unavailable and the researcher does not supply a translation.

## Operational ingestion is separate

Scheduled or optional ingestion may include Stack Exchange, Global Voices, The Conversation, European Commission Presscorner, Typst Forum, Fedora Discussion, Wikimedia talk-page metadata, or explicitly configured RSS/MOIS feeds. These operational records are not automatically part of the public search response or the country comparison. Ingested metadata has separate retention and rights controls.

## Not active in visitor search

- GDELT live search is retired after provider rate-limit/timeout failures.
- DEV Community/Forem is excluded even though its public API exposes articles and comments: the site's [Terms](https://dev.to/terms) grant only personal, non-commercial transitory viewing and expressly prohibit public display, copying, or mirroring. Atlas does not query or scrape it; add only after compatible written permission or a clear content license.
- GitHub public issue/discussion search is not integrated. Although public REST search can be queried without a token, GitHub's [Acceptable Use Policies](https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies) restrict use of public non-personal information for research to cases where resulting publications are open access. Atlas is an interactive product, not an open-access research publication; do not add this source without a clear applicable permission basis.
- Stocktwits is not integrated. The operator currently says it is not accepting new API registrations, and its terms prohibit automated extraction except through written authorization or an approved API/developer offering. Public webpages are not a permitted substitute for API access; see [developer access](https://api.stocktwits.com/developers) and [terms](https://stocktwits.com/about/legal/terms/).
- YouTube comments are not integrated. The Data API requires a Google Cloud project/API key and has a small default search quota; its developer policies require YouTube-specific source presentation and restrict combining/aggregating API data across sources. Atlas's core feature is a cross-source, cross-community comparison, so this is not a compliant drop-in source without separate policy review or approval. See [quota](https://developers.google.com/youtube/v3/getting-started) and [developer policies](https://developers.google.com/youtube/terms/developer-policies-guide).
- Wikimedia talk pages and scheduled feeds are operational/research-context sources and are not included in this focused conversation search.
- Wikinews is archived, not a current source.
- X, Naver, and Kakao forum search are not integrated. Reddit is excluded under its current research/API restrictions. Do not scrape around access controls, terms, or rate limits.
