# Atlas source register

This describes the visitor-facing workflow in the current code. `/sources` is the live operational register; [data-sources.md](data-sources.md) documents search limits and privacy.

## Search providers

| Source | Product role | Scope and limitation |
| --- | --- | --- |
| Bluesky AppView | Public social discussion | Public search, last seven days, up to 25 indexed posts per phrase. English baseline adds `lang:en`; the selected lens uses its query phrase. Language is not author geolocation; excerpts are transient. |
| Lemmy instances | Public federated forum posts | Public API query to `lemmy.world`, `discuss.tchncs.de`, `feddit.org`, `jlai.lu`, `sopuli.xyz`, and `sh.itjust.works`; up to 20 recent matching posts per instance in seven days. Only the Germany- and France-focused community lenses use Lemmy's `local` listing (communities hosted on those servers); other country lenses use `all` (federated search) because no country-specific Lemmy server is configured. A server's country, language, and locally hosted communities do not verify poster residence or nationality. Finnish/English and Canadian English/French servers are general community views, not representative resident samples. Language IDs are instance-specific and displayed as unmapped IDs. Federation may duplicate posts; no blanket reuse license is implied. Instance terms and privacy links are listed on `/sources`. |
| Mastodon instances | Public hashtag conversation | Public hashtag timeline; posts older than 30 days are filtered, with up to 20 API items per tag and up to three bounded topic tags per selected instance. Tags are separate query/status/provenance views; untagged posts and posts without those tags are missed, and broad terms can add noise. Korean-, Japanese-, German-, French-, Brazilian Portuguese-, and Spanish-language/community-focused servers are available for those lenses, but instance membership does not verify author residence or nationality; there is no reviewed local-focused instance configured for India. Accounts self-marked automated by the instance remain citable but their text is excluded from AI summaries. Atlas does not use full-text status search because Mastodon's official docs say it depends on server search configuration and authenticated requests. Instances can restrict public access. |
| Stack Exchange API | Licensed expert Q&A | Economics, Quantitative Finance, and Personal Finance & Money; Japanese, Portuguese, or Spanish Stack Overflow titles for the corresponding language lens where configured. Title-only matches, individually CC BY-SA items with author/license attribution; 30-day visitor search. One platform operator, not general opinion. |
| The Conversation Atom feeds | Expert analysis context | Six first-party English editions; up to five exact headline matches per edition in 30 days, with author/date/link and item-level Creative Commons attribution/no-derivatives notice. Titles only are returned; one publisher's editions are not independent operators or audience/geographic samples and are excluded from AI discussion synthesis. |
| Crossref | Global scholarly research context | Free public API, no key or signup; one small title search, up to 12 DOI-linked records published in the last five years. Bibliographic metadata only, no abstract/body; not a community or country sample and not a measure of study quality. |
| OpenAlex | Global scholarly research context | Keyless casual-use API, no account or payment method; up to 25 provider hits are checked locally and at most 12 five-year title matches are returned. Only ID, DOI, title, date, type, and open-access flag are requested; no abstracts/authors. Metadata is CC0. Keyless quotas are shared/provider-controlled and Atlas cannot guarantee availability; this evidence is not discussion, country opinion, or a study-quality rating. |
| arXiv | Open preprint metadata | Public keyless Atom API; at most 12 five-year title matches, retaining title/ID/date/category and discarding abstracts/authors. Metadata is CC0; underlying papers have item-specific rights. Preprints may not be peer reviewed and do not represent discussion or country views. Identical queries are cached in volatile server memory for 24 hours and upstream requests are spaced at least three seconds apart per instance. Required arXiv acknowledgment appears in the source register. |
| Manifold Markets | Crowd-forecast context | Read-only, no-key public API; up to 20 open binary market matches sorted by recent volume. Atlas keeps only active MANA play-money markets with positive recent volume and liquidity, and displays their probability and MANA measures below the summaries. This is one self-selected forecasting platform, not real-money price discovery, a representative survey, a verified probability, or a country view. It is excluded from AI summaries. Its documented API permits non-commercial/personal projects; a commercial Atlas would need a separate written agreement. |
| Reddit | Excluded | Reddit's current developer guidance says research use must go through its separate Reddit for Researchers program; ordinary Data API access is not an authorized research route. No API requests or page scraping are made. Reconsider only if Atlas qualifies for and receives compatible research-program authorization. |
| Global Voices editions | International reporting context | Non-U.S. lens only: twelve language editions, headline metadata only, 30-day window and capped results. One publisher's editions are not independent forums or country samples. |

The form compares a baseline query with one selected country/language lens from eight options: U.S./English, South Korea/Korean, Japan/Japanese, Germany/German, France/French, Brazil/Portuguese, India/Hindi, and Spain/Spanish. Baseline language handling varies by provider; it is not a verified U.S. sample. These are query and community lenses, not verified contributor geographies. The product presents the baseline and selected-language summaries separately and lists sources beneath; it does not combine the international sample into one national-opinion estimate.

Hacker News is retired from visitor search while content display/reuse review is unresolved. Stack Exchange title-only Q&A is included as a separate evidence class. Wikimedia talk pages and scheduled feeds shown in operational health are not automatically included in this search. Metaculus was screened but not added: its current API requires authenticated requests, whereas this product is limited to no-login public sources; no account token or access request was created.

Misskey.io was screened but not added. Its API documentation lists `POST /api/notes/search` as not requiring a credential, but its operator's terms say data collection beyond personal use is prohibited and require advance contact for annual collection of 500 or more records. A public endpoint is not blanket permission; Atlas cannot enforce that annual aggregate limit across serverless instances and visitors, so it remains off unless the operator clarifies/authorizes the intended use. See [Misskey.io API docs](https://api-doc.misskey.io/api-7254035) and [MisskeyHQ terms](https://support.misskey.io/ja/articles/14193143-%E5%88%A9%E7%94%A8%E8%A6%8F%E7%B4%84).

AI translation and summaries are attempted automatically when a visitor submits a search; the privacy notice describes that the topic and up to 16 short excerpts may be sent to Groq. Embedded links, email addresses, and @handles are removed from excerpts; citation URLs and attribution fields are not sent. There is no per-search AI opt-in. Server configuration (`GROQ_FREE_TIER_ENABLED=true` and a private key) is required. The code does not verify an account's Groq billing status; operators must independently confirm free-tier eligibility and must not enable paid billing for Atlas. Groq's free availability and rate limits are not guaranteed by Atlas. Groq's [data handling](https://console.groq.com/docs/your-data) and [billing FAQ](https://console.groq.com/docs/billing-faqs) apply; see Atlas's [privacy notice](https://signal-scout-xi-ruby.vercel.app/privacy).

## Operational ingestion is separate

Scheduled or optional ingestion may include Stack Exchange, Global Voices, The Conversation, European Commission Presscorner, Typst Forum, Fedora Discussion, Wikimedia talk-page metadata, or explicitly configured RSS/MOIS feeds. These operational records are not automatically part of the public search response or the country comparison. Ingested metadata has separate retention and rights controls.

## Not active in visitor search

- GDELT live search is retired after provider rate-limit/timeout failures.
- GitHub public issue/discussion search is not integrated. Although public REST search can be queried without a token, GitHub's [Acceptable Use Policies](https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies) restrict use of public non-personal information for research to cases where resulting publications are open access. Atlas is an interactive product, not an open-access research publication; do not add this source without a clear applicable permission basis.
- Wikimedia talk pages and scheduled feeds are operational/research-context sources and are not included in this focused conversation search.
- Wikinews is archived, not a current source.
- YouTube comments are not implemented; API keys, quotas, and additional policy requirements apply.
- X, Naver, and Kakao forum search are not integrated. Reddit is excluded under its current research/API restrictions. Do not scrape around access controls, terms, or rate limits.
